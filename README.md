Windows 桌面壁纸自动轮换工具。图来自两个公开图源（只下到你自己电脑上，不随程序分发）：

| 图源 | 说明 |
|---|---|
| **必应每日一图** | 微软必应每天换的那张，4K 原图 |
| **Windows 聚焦** | 微软官方聚焦图库，一次能刷一批，也是 4K |

> 本项目与任何图源厂商无隶属关系；「必应」「Windows 聚焦」等名称只用于描述图片来源。
> 图片版权归原提供方，仅供个人桌面使用，请遵守各图源的使用条款。

它有几个地方跟别的壁纸软件不一样：

- **不用安装** —— 下载一个 exe，双击就用
- **不要管理员权限**，不写自启动注册表项、不装服务与计划任务
  （「开机自动换壁纸」是**在「启动」文件夹里放一个快捷方式**实现的；控制台「更换节奏 → 开机自动换」可一键关闭并删除它）
- **改写系统的只有一件事**：设壁纸走 Windows 标准做法
  （`SystemParametersInfo(SPI_SETDESKWALLPAPER)`），其中「壁纸填充方式」写在 Windows 自己的
  `HKCU\Control Panel\Desktop`（`WallpaperStyle` / `TileWallpaper`，与系统「个性化」是同一个位置），
  **写前先比对，值相同就不写；不改系统代理、不改 DNS、不改 hosts**
- **后台换图时一个窗口都不闪**，你根本感觉不到它在跑
- **几天没开机也不漏图** —— 错过的必应壁纸会自动补齐
- **图片都存在你自己电脑上**，不上传任何东西

## 三步用起来

**第 1 步** —— 解压，双击 `桌面壁纸.exe`，浏览器会自动打开控制台。

**第 2 步** —— 第一次打开，它会自动下载今天的必应图 + 一批聚焦图，屏幕上会告诉你壁纸存在哪。等几十秒就好。

**第 3 步** —— 想让它以后开机自己换：控制台「更换节奏 → 开机自动换」打开。

```
想立刻看效果？控制台点「立即换一张」。
```

> 开这个开关不用管理员。它只是在 Windows「启动」文件夹里放一个快捷方式而已。

> 想先看它长什么样：[演示视频](docs/demo/index.html)（页面内嵌播放，**v2.4.0 网页控制台实录**：39 秒、全字幕）。

## 控制台上都有什么

只在你自己的电脑上，不联网、不上传任何东西；关掉标签页不影响换壁纸）。

### 状态一眼看见

顶部写着**脚本版本 / 主程序版本 / 数据目录**，右边一行是「自动更换中 · 约 N 分钟后换」——
不用记菜单层级，当前是什么状态、下一次什么时候换，都在明处。
数据不对时（比如库里一张图都没有、保存位置写不进去），「当前壁纸」会直接用文字说明。

### 改哪一项都立刻生效

所有开关、滑块、下拉框改完**当场落盘并生效**，没有"保存"按钮，也不用重启。
页面每 20 秒自己刷新一次状态；想立刻刷新点底部「刷新状态」。

### 必应模式（只换必应、一天一张）

打开「更换节奏 → 必应模式」后：**立刻**换成"今天这张"必应图（几秒到十几秒，要下 4K 原图），
之后**一天一换** —— 每天后台第一次跑时换成当天的必应图，不再抓聚焦、也不按间隔轮换。
重启电脑后贴回的还是当天那张。关掉就恢复正常轮换。

### 后台任务（补货 / 补漏 / 补齐某月）

这三件事都在「高级」里，点了就返回，真正干活在**独立进程**里跑（不占界面）：
补几张新图、补漏必应（只下载不切壁纸）、补齐某月（写成 `2024-08`）。
进度写在控制台右下角「最近动作」（就是日志尾巴）。

### 图源抓取纪律与授权

聚焦和必应两套图库共用同一套抓取纪律（程序内部是**可插拔图源**结构：每个源各自一个目录、各自的去重记录、
各自的容量上限，0 = 不限），让有限的源池永远有图可换：**限速慢慢补**（每源单轮 6 张 · 每天 20 张）、
**库满了就不补**、**连续 3 轮没新图就退避**、**老图够 30 天回炉**。控制台「高级 → 源池状态」那一行，
直接告诉你现在是还有新图、进入老图循环、还是源池已抓到尽头（等官方更新，下次尝试 时间）。

> 四条机制的默认值与说明、为什么这样设计、以及抓到头为什么**不报错也不空转**，见
> [CONTRIBUTING.md](docs/CONTRIBUTING.md) 第十节。

**授权（重要）**：

- 图只**下载到你自己电脑上**，不随发行版打包分发，也不上传到任何地方；
- 接入**公版库**类图源时，程序**逐张校验公版标记**，非公域的一律不看；
- 图片版权归**原提供方**，仅供个人桌面使用，请遵守各图源的使用条款；
- 本项目与各图源厂商**均无隶属关系**，名称只用于描述图片来源。

「更换节奏 → 壁纸填充方式」改完**立刻应用到当前这张壁纸**，当场就能看到效果。

> 退出请点控制台底部「退出控制台」（关掉浏览器标签页只是关掉"遥控器"，后台照换）。

看到喜欢的图，点「收藏这张」就收下了，再点一次取消。收藏够了到
「更换节奏 → 只在收藏里轮换」打开，以后换出来的都是你自己挑过的图。

## 壁纸存哪？能自己删吗？

默认存在**「图片」文件夹里的「壁纸」**，下面两个子目录：`必应`（必应每日一图）与 `聚焦`（Windows 聚焦）；位置随时可以在控制台「高级 → 壁纸保存位置」里改。

**库里的图你随便删、随便挪、随便拷走，程序完全不受影响**：删掉的不再排进轮换、也不会被重新下载回来；整个库挪走了，到「高级 → 壁纸保存位置」指过去即可；正在用的那张被移走，「当前壁纸」会如实写出来，换一张就更新了。

> 「图片」文件夹在 C 盘时怎么找现成能放图的位置、以及为什么不会凭空多造一个文件夹（v1.6.2 定下的行为），见 [CONTRIBUTING.md](docs/CONTRIBUTING.md) 第十节；完整口径见 [CHANGELOG.md](docs/CHANGELOG.md)。

## 常见问题

<details>
<summary><b>常见问题</b>（点击展开）</summary>


| 问 | 答 |
|---|---|
| **双击没反应？** | 多半是安全软件拦了，把它加入信任就行。程序联网只有这几种情况：从 bing.com 与微软官方接口下图、检查更新时访问 Gitee / GitHub、补漏与归档时可能经第三方 GitHub 加速节点（`ghfast.top` / `gh-proxy.com`）中转。**全程没有任何上传行为。** |
| **中文显示成乱码？** | 系统「非 Unicode 程序语言」要设成「中文(简体, 中国)」。 |
| **会不会拖慢电脑？** | 只有「开机自动换」开着时后台才有一个进程，平时占 30 MB 左右，绝大多数时间在睡觉。关掉就完全不占。 |
| **提示某个盘「写不进去」？** | 那是这台机器那个盘的权限设置（常见于用第三方分区工具格的盘），不是程序不支持它。换个盘（控制台「高级 → 壁纸保存位置」），或者把这个程序用管理员身份运行一次让它把目录建好 —— 壁纸放哪个盘都能用。 |
| **不想用了怎么卸？** | 控制台「更换节奏 → 开机自动换」关掉 → 删掉 exe → 想连配置也清掉就再删数据目录（控制台底部「打开数据目录」）。**下载的壁纸一张都不会被删。** |

</details>

## 自动更新是怎么保证安全的

在线升级会先做**两道校验**，全过才替换文件：

1. **Ed25519 公钥验签**：线上 `version.json` 必须带一份同目录的 `version.json.sig`
   （由维护者的离线私钥签名），客户端用内置公钥验签，**验不过一律拒绝、保留旧版**；
2. **sha256 指纹**：脚本与主程序下载后逐字节比对 `version.json` 里声明的 sha256，对不上就丢弃。

签名**私钥只在维护者机器上、绝不进仓库**（公钥公开无妨，本来就随程序分发）。
要说清能力边界：这道验签防的是「升级源被篡改 / 中间人换包」，**防不了**维护者机器上的私钥本身被偷，
也**不等于** Windows 代码签名证书（那是另一回事，见下面「Code signing policy」）。

## 路线图（Roadmap）

按优先级从高到低，都是已经排进计划、能落到代码上的事：

1. **代码签名**：README 已公开[代码签名政策](#code-signing-policy代码签名政策)（申请 SignPath 免费签名）。
   通过之后产物在构建流程中自动签名，用于缓解"单文件自解压 + 自动升级"被安全软件误报的问题。
   现状说明：**目前发布的 exe 没有数字签名**，所以杀软可能报毒 —— 请以发行页上的 SHA256 自行核对。
2. **更多图源评估**：现在只有必应每日一图与 Windows 聚焦两个微软官方图源。
   程序内部已经是可插拔图源结构（加一个源只需加一条定义 + 它的搜索/取图两个函数），
   评估新图源的标准是"本地优先、失败可回退、不收集数据"，外加一条**出图必须适合当壁纸**
   （接近 16:9：方形图铺满会裁掉主体，超宽长卷铺满会留两条空）——
   2026-10-09 就因为这个原因摘掉了两个试过的图源。宁可不加也不塞一个会拖慢启动、或出的图不能看的源。
3. **安装体验优化**：保持绿色单文件（不引入安装器），把"首次运行"再做省心一点 ——
   减少第一次双击时的等待与提示条数，让"下载 → 双击 → 有壁纸"这条路上没有需要读文档的步骤。

## 从源码构建

不想下载现成 exe、想自己从源码打一份的话，最短路径就是下面三步（**Windows 10/11 x64 + Python 3.11 及以上**）：

```powershell
pip install "pyinstaller==6.22.3"        # 只有打包用得到；运行主程序零第三方依赖
python build-exe.py --release            # 出成品
python tools/preflight_release.py        # 发版前自检：全绿才算可用
```

- **产物**：仓库根目录的 `桌面壁纸.exe`（固定名，日常就这一份）；加 `--release` 还会多出 `桌面壁纸-v<版本>.exe` 与发给用户的 `MSWallpaperAssistant-v<版本>.zip`。
  文件名以 `launcher.py` 的 `EXE_STEM` 为唯一来源；`build-exe.py`、`tools/publish.py`、`tools/make_version_json.py`、发版自检都从那里推导，不再各写一遍。
- **怎么核对**：`python tools/preflight_release.py` 会查 Python 语法、`.ps1` 的 BOM 与语法、版本一致性、成品与升级源同源等；`[SKIP]` 是「本机没装依赖 / 没有成品 exe / 没联网」，不算失败，`[FAIL]` 一条都不许有。
- 改完代码要跑哪些命令、容器/CI 里怎么打、键位与设置全表在哪，见 [CONTRIBUTING.md](docs/CONTRIBUTING.md) 第四节；仓库结构与「改哪儿」见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)。
