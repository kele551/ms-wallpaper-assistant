# 安全政策（Security Policy）

> 桌面壁纸 —— 作者：**海风（kele551）** · <https://github.com/kele551/ms-wallpaper-assistant>

## 支持范围

只对**最新发布版本**提供安全修复。请先确认你用的是最新版（菜单标题上有版本号，或右键 exe → 属性 → 详细信息）。

| 版本 | 是否支持安全修复 |
|---|---|
| 最新发布版（版本号见仓库 Releases 页或菜单标题） | ✅ |
| 更早的版本 | ❌ 请先升级；老版本的问题通常在新版已修 |
| 自己改过源码再打包的 | ❌ 请先在**未修改的**最新版上复现 |

## 怎么私下报告漏洞

**请不要开公开 Issue。** 这个项目有以下两条私下渠道：

1. **GitHub 私密漏洞报告（推荐）**：仓库页面 → **Security** 标签页 → **Report a vulnerability**。
   这是 GitHub 提供的私密通道，只有维护者能看到，报告与讨论都留档在仓库里，不会公开。
   （维护者当前正在仓库设置里开启这一功能；如果那个按钮还看不到，请走第 2 条，并在报告里说明。）
2. **仓库 Issues 里先说一句，但别写细节**：开一条 Issue，标题写「安全相关问题，请私下联系我」，
   **正文不要写任何漏洞细节、复现步骤或影响范围**，只留一个你可以被联系到的方式。
   维护者会尽快建立私密渠道，再请你把细节发过来。

无论走哪条，都欢迎先附上：程序版本号、Windows 版本、以及"哪一类问题"（例如：升级链路完整性、脚本注入、越权读写文件）。

## 响应时限

| 阶段 | 承诺 |
|---|---|
| 确认收到报告 | **3 天内** |
| 初步判断（是不是真问题、严重度） | **7 天内** |
| 修复版本 | 视严重度：能直接导致数据丢失或代码执行的，优先修；其余按"版本号只给新功能用"的节奏攒进下一个功能版 |

修好之后，如果你愿意，会在发布说明里致谢（也可以要求匿名）。

## 这个项目的威胁模型（先说清哪些算、哪些不算）

**算漏洞**，欢迎报告：

- 自动升级链路的**完整性**问题：升级源被替换/中间人改写后程序仍会安装（含 `version.json` 缺少 `sha256` 字段时的行为）
- 下载下来的图片/脚本被当成可执行内容处理（脚本注入、路径穿越）
- 程序能**越权**读写它不该碰的文件（数据目录之外、其它用户目录）
- 未经用户同意就把数据发到网络上（本项目承诺**不收集、不上传任何用户数据**）
- 「卸载/退出」之后仍留下会自行运行的东西（服务、计划任务、**注册表自启动项**）
  - **边界说明（2026-10-10 补，避免"拿自己的行为当漏洞"）**：
    「开机自动换壁纸」的实现方式是**在「启动」文件夹里放一个快捷方式**，
    **不写注册表自启动项、不建计划任务、不装服务**（这三样代码里一处都没有）。
    菜单 `[B]` 一键关闭并删除它，`[S]`→`[6]` 关闭自动换也会删。
    **卸载前请先按 `[B]`** —— 否则那个快捷方式会留在启动文件夹里。

**不算漏洞**（属于已知边界，README 里已写明）：

- **杀软报毒**。程序没有代码签名，又是单文件自解压 + 自动升级下载脚本，容易触发启发式误判 ——
  这属于误报，请以发行页上的 SHA256 自行核对来源。详见 [CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md)。
- 程序会写 `HKCU\Control Panel\Desktop` 的 `WallpaperStyle` / `TileWallpaper`（Windows 自己的壁纸设置，
  与系统「个性化」同一位置，写前先比对）。这是设计如此，不是漏洞。
- 壁纸图片本身来自微软官方图源，图片内容问题请找图源方。

## 报告里请不要包含

不要发送你的个人数据、账号凭据、或与漏洞无关的隐私内容。日志（`wallpaper.log`）里没有隐私信息，可以直接贴。
