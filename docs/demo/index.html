微软壁纸助手 · 演示视频

必应每日一图 + Windows 聚焦图库，自动换桌面 —— 不打扰、休眠友好、升级可回滚
时长 2 分 05 秒　·　文件大小 6.5 MB　·　格式 MP4（H.264），手机与电脑浏览器均可直接播放
关于本项目
  • 双图源：必应每日一图 + Windows 聚焦图库（4K、带中文标题）
  • 离开电脑、锁屏时不换图；对休眠友好，默认 30 分钟一换
  • 聚焦图库默认上限 100 张，超出自动清理最旧的 6 张
  • 绿色单文件，免安装；自动升级带 SHA256 校验，失败可回退
